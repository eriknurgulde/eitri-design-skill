# Page Patterns, Flows and Voice

## Product flows

Each breakpoint is a self-contained prototype flow (never link across breakpoints):

1. **Landing**: cookie consent (first visit) → Home.
2. **Authentication**: Sign In ↔ Sign Up; Sign In → Forgot Password → Email sent → Back to sign in.
3. **Onboarding**: Onboarding 1 (intro) → 2 → 3 → 4 → 5 (questions) → Offer (pricing).
4. **Workspace**: Profile (dashboard) ↔ Project description → Project build; Settings.

## Page patterns

### Landing (Home)
1. **Hero**: `STOP STUDYING.` (White) / `START [video chip] DOING.` (Hot Orange), Manrope ExtraBold uppercase, centered; skills node-graph band; one-line value prop; primary CTA "Enter the workspace ↗".
2. **Knowing vs doing**: H2 `KNOWING ISN'T THE SAME AS DOING.` + intro; Comparison cards (Theory vs Practice); chart "Skill development × Knowledge development" (active-learning curve in Forge Orange with glow, passive in Ash).
3. **Do it**: `DON'T JUST STUDY THE WORK.` + Climate Crisis `DO IT.`; 4 process steps on one continuous heat-gradient path (Start with a real brief → Work through the process → Get your work reviewed → Build evidence of your skills).
4. **Your career**: Climate Crisis `YOUR CAREER` + `STARTS WITH THE WORK.`; 4 Role cards (Software Engineering, Data & Analytics, AI & Machine Learning, Product & Design).

### Authentication
Heat-glow background (blurred ember images/circles), site-tree sidebar on desktop/laptop, glass form panel. Typing-animation title ("YOUR WORKSPACE AWAITS_", "BACK TO THE BENCH_"). Fields, Remember me + Forgot password?, primary "Enter your workspace ↗", "or" divider, Continue with Google / Apple, account switch link.

### Onboarding
Progress header; Climate Crisis question (`WHERE ARE YOU STARTING FROM?`); one-line helper; 5 Option cards; Continue (disabled until a choice). Intro step: `LET'S GET YOU TO WORK.`, node graph, three benefit points with orange icons, "Set up my workspace ↗".

### Offer (pricing)
`YOUR NEXT STEP IS` + Climate Crisis `REAL WORK.` (Forge Orange); subline; Starter / Pro (featured) / Pro+ plan cards.

### Workspace
- **Profile**: `WELCOME, JORDAN`; avatar + name + role + location + PRO+ badge; three big stats (`08 Tasks completed`); My work carousel; My skills grid; Activity feed + latest mentor feedback; Recommended carousel.
- **Project description**: breadcrumb (mono), project title (uppercase), subtitle, topic tags, stats; numbered sections with mono indices (`01 / CONTEXT · THE BRIEF`, `02 / GOALS · OBJECTIVES`, `03 / OUTPUT · DELIVERABLES`, `04 / PLAN · TASKS`); details panel with "Start building ↗".
- **Project build**: task progress bar; current task (status label, checklist, resources), mentor note (Ember panel), upload deliverable (dropzone, notes, Submit task / Save draft); task stepper.
- **Settings**: Account, Plan, Notifications (toggles), Privacy, Danger zone (Log out / Delete account).

## Recurring visual devices

- **Mono section index**: `01 / CONTEXT` in Forge Orange above an uppercase title.
- **Middle-dot lists**: `CODE · DEBUG · SHIP`, `LEVEL 3 · ADVANCED`, `Est. 3 h · Due Oct 8`.
- **Typing cursor**: titles ending in `_` that type themselves in.
- **Heat path / glow**: gradient lines and glows that "heat up" as the user progresses.
- **Image chip**: a small dotted/pixel video image inline between headline words.
- **Skills node graph**: constellation of skills around "Eitri", heat-colored hubs.

## Voice and copy

- **Direct, practical, imperative.** "Stop studying. Start doing." "Don't just study the work. Do it."
- **About real work, not lessons**: briefs, deliverables, mentors, reviews, portfolios, stakeholders.
- **Short.** Headlines ≤ 6 words; body ≤ 2 sentences; buttons 1–3 words + ↗ for forward moves.
- **Honest and encouraging**, never hype: "No need to know everything already." "You can pause anytime — progress is saved automatically."
- **Uppercase** for headings and labels; sentence case for body, buttons, and field labels.
- Examples: "Enter the workspace", "Set up my workspace", "Start building", "Explore projects", "Submit task", "Choose Pro".
